03 / 06
The Demo App

NovaPulse has intentional bugs —
here's what Fullstory will catch.

Four deliberate issues are built into the demo, each one a realistic bug type that real products ship to production.

Dead click
Export button — looks active, has no onclick handler. Every click goes nowhere. Fullstory detects rapid repeated clicks.
Console error
Filter Tags input — calls processTagFilter() which doesn't exist. ReferenceError fires on every keystroke.
Invisible UI
Submit button — background color identical to its container. Users can't see it, rage-click the surrounding area.
Z-index overlap
Manage Billing — a transparent div sits above the button, intercepting all clicks before they reach the handler.

Deployment Pipeline

PR merged → live in 60 seconds.
GitHub Actions handles it.

Once Claude's PR is opened, a reviewer (or auto-merge rule) merges it. GitHub Actions immediately deploys to GitHub Pages.

Claude's PR includes full explanation of each fix
GitHub Actions triggers
deploy.yml detects merge to main branch
Pages deploy completes
